# 数据库

这里说明当前 `gint` 生态下常见的数据库接入方式。

## 当前建议

`gint` 一般与 GORM 或标准 `database/sql` 搭配使用。数据库初始化通常放在应用接线层，而不是依赖一个框架级全局单例。

## 常见模式

```go
db, err := gorm.Open(postgres.Open(dsn), &gorm.Config{})
if err != nil {
	panic(err)
}

sqlDB, err := db.DB()
if err != nil {
	panic(err)
}

sqlDB.SetMaxIdleConns(10)
sqlDB.SetMaxOpenConns(30)
sqlDB.SetConnMaxLifetime(5 * time.Minute)
```

## 建议

- 连接池参数放到应用配置中
- 启动阶段主动 Ping 数据库
- 查询尽量带上请求上下文
- 迁移逻辑放在服务启动接线附近更清晰
