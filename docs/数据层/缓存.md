# 缓存

缓存模块提供统一抽象，并支持内存与 Redis 两种实现。

## 实现

- `cache/memory`
- `cache/redis`

## 基本使用

```go
ctx := context.Background()
c := memory.New()
cache.SetDefault(c)

_ = cache.Set(ctx, "user:1", []byte("tom"), 10*time.Minute)
val, err := cache.Get(ctx, "user:1")
_ = val
_ = err
```

## 类型安全缓存

```go
type User struct {
	ID   string `json:"id"`
	Name string `json:"name"`
}

userCache := cache.NewTypedCache[User](c, "user:")
_ = userCache.Set(ctx, "1", User{ID: "1", Name: "tom"}, 5*time.Minute)
u, _ := userCache.Get(ctx, "1")
_ = u
```

## 说明

- 使用全局缓存辅助方法前，需要先设置默认实例
- 缓存未命中建议用 `errors.Is(err, cache.ErrCacheNotFound)` 判断
- 多实例生产环境优先使用 Redis 缓存
