# 服务间调用

gint 提供服务间HTTP客户端，支持超时、重试、追踪传播。

## 概述

服务间调用特性：
- 自动传播追踪上下文
- 自动传播用户身份
- 支持超时配置
- 支持重试机制

## 基本使用

### 创建客户端

```go
import "github.com/ink-yht-code/gint/ghttp"

// 创建客户端
client := ghttp.NewClient(
    ghttp.WithTimeout(5*time.Second),
    ghttp.WithRetry(3, 100*time.Millisecond),
)
```

### 发送请求

```go
// GET请求
var result UserResponse
resp, err := client.Get(ctx, "http://user-service/api/users/123", &result)

// POST请求
req := &CreateOrderReq{UserId: 123, ProductId: 456}
resp, err := client.Post(ctx, "http://order-service/api/orders", req, &result)

// PUT请求
resp, err := client.Put(ctx, "http://user-service/api/users/123", updateReq, &result)

// DELETE请求
resp, err := client.Delete(ctx, "http://order-service/api/orders/123", nil)
```

### 便捷方法

```go
// 快捷GET
var result UserResponse
err := ghttp.Get(ctx, "http://user-service/api/users/123", &result)

// 快捷POST
err := ghttp.Post(ctx, "http://order-service/api/orders", req, &result)
```

## 配置选项

```go
type ClientConfig struct {
    Timeout        time.Duration // 请求超时
    RetryCount     int           // 重试次数
    RetryWaitMin   time.Duration // 最小重试等待
    RetryWaitMax   time.Duration // 最大重试等待
    MaxIdleConns   int           // 最大空闲连接
    IdleConnTimeout time.Duration // 空闲连接超时
}
```

### 完整配置

```go
client := ghttp.NewClient(
    ghttp.WithTimeout(10*time.Second),
    ghttp.WithRetry(3, 500*time.Millisecond),
    ghttp.WithMaxIdleConns(100),
    ghttp.WithIdleConnTimeout(90*time.Second),
)
```

## 追踪传播

自动传播追踪上下文和用户身份：

```go
// 服务A
func Handler(c *gin.Context) {
    ctx := c.Request.Context()
    
    // 调用服务B，自动传播追踪上下文
    var result Response
    client.Get(ctx, "http://service-b/api/data", &result)
    
    // TraceID 和 UserContext 自动传播
}
```

### 传播的请求头

| 请求头 | 内容 |
|--------|------|
| `X-Trace-ID` | 链路追踪ID |
| `X-User-ID` | 用户ID |
| `X-User-Role` | 用户角色 |
| `X-Tenant-ID` | 租户ID |
| `traceparent` | OpenTelemetry追踪 |

## 完整示例

```go
package main

import (
    "context"
    "time"
    
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint"
    "github.com/ink-yht-code/gint/ghttp"
    "github.com/ink-yht-code/gint/middlewares/trace"
)

var client *ghttp.Client

func main() {
    // 创建HTTP客户端
    client = ghttp.NewClient(
        ghttp.WithTimeout(5*time.Second),
        ghttp.WithRetry(3, 100*time.Millisecond),
    )
    
    r := gin.Default()
    
    // 链路追踪中间件
    r.Use(trace.Middleware())
    
    // 业务路由
    r.GET("/api/orders/:id", gint.U(GetOrder))
    
    r.Run(":8080")
}

type GetOrderReq struct {
    ID int64 `uri:"id" validate:"required"`
}

type OrderDetail struct {
    Order  *Order        `json:"order"`
    User   *User         `json:"user"`
    Items  []*OrderItem  `json:"items"`
}

func GetOrder(c *gin.Context, req GetOrderReq) (gint.Result, error) {
    ctx := c.Request.Context()
    
    // 获取订单
    var order Order
    _, err := client.Get(ctx, "http://order-service/api/orders/"+string(req.ID), &order)
    if err != nil {
        return gint.Result{}, err
    }
    
    // 获取用户信息
    var user User
    _, err = client.Get(ctx, "http://user-service/api/users/"+string(order.UserId), &user)
    if err != nil {
        return gint.Result{}, err
    }
    
    // 获取订单项
    var items []OrderItem
    _, err = client.Get(ctx, "http://order-service/api/orders/"+string(req.ID)+"/items", &items)
    if err != nil {
        return gint.Result{}, err
    }
    
    return gint.Result{Data: OrderDetail{
        Order: &order,
        User:  &user,
        Items: items,
    }}, nil
}
```
