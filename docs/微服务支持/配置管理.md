# 配置管理

`gint/config` 支持从文件、环境变量和内存映射中加载配置。

## 功能

- 多配置源加载
- 支持 `db.host` 这类点路径访问
- 提供 `GetString`、`GetInt`、`GetBool` 等类型安全读取
- 支持通过 `Unmarshal` 解析到结构体

## 快速开始

```go
cfg, err := config.LoadApp("config/dev.yaml")
if err != nil {
	panic(err)
}
```

`LoadApp` 通常会加载：

- 指定配置文件或默认 `config.yaml`
- `APP_` 前缀的环境变量

## 自定义配置源

```go
cfg := config.New(
	config.WithFile("config.yaml"),
	config.WithFile("config.local.yaml"),
	config.WithEnv("APP_"),
	config.WithMap(map[string]any{
		"debug": true,
	}),
)
```

## 常用读取方法

```go
host := cfg.GetString("db.host", "localhost")
port := cfg.GetInt("db.port", 5432)
debug := cfg.GetBool("debug", false)
rate := cfg.GetFloat64("rate", 0.5)
hosts := cfg.GetStringSlice("hosts", []string{"localhost"})
```

## 结构体解析示例

```go
type DBConfig struct {
	Host string `yaml:"host"`
	Port int    `yaml:"port"`
}

var dbCfg DBConfig
if err := cfg.Unmarshal("db", &dbCfg); err != nil {
	panic(err)
}
```

## 环境变量映射

示例：

- `APP_SERVER_PORT` -> `server.port`
- `APP_DB_HOST` -> `db.host`

## 建议

- 启动阶段配置加载失败要快速失败
- 生产环境敏感信息优先放环境变量或密钥系统
- 尽量使用类型安全方法或 `Unmarshal`
