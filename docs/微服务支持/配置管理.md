# 配置管理

gint 提供多源配置管理，支持文件、环境变量、内存映射等多种配置源。

## 概述

配置管理特性：
- 多源配置：文件/YAML/JSON/环境变量
- 层级Key访问：`db.host`
- 类型安全获取：GetString/GetInt/GetBool
- 结构体解析：Unmarshal

## 基本使用

### 快捷加载

```go
import "github.com/ink-yht-code/gint/config"

// 加载 config.yaml + 环境变量 APP_*
cfg, err := config.LoadApp()
```

### 自定义配置源

```go
cfg := config.New(
    config.WithFile("config.yaml"),
    config.WithFile("config.local.yaml"),
    config.WithEnv("APP_"),
    config.WithMap(map[string]interface{}{
        "debug": true,
    }),
)
```

## 配置源

### 文件配置

```yaml
# config.yaml
server:
  port: 8080
  mode: release

db:
  host: localhost
  port: 3306
  name: myapp
  user: root
  password: secret

redis:
  host: localhost
  port: 6379
  db: 0

log:
  level: info
  output: stdout
```

```go
cfg := config.New(
    config.WithFile("config.yaml"),
)
```

### 环境变量配置

```bash
# 环境变量
export APP_SERVER_PORT=8080
export APP_DB_HOST=localhost
export APP_DB_PORT=3306
export APP_REDIS_HOST=localhost
```

```go
cfg := config.New(
    config.WithEnv("APP_"),
)

// APP_SERVER_PORT -> server.port
// APP_DB_HOST -> db.host
```

### 内存配置

```go
cfg := config.New(
    config.WithMap(map[string]interface{}{
        "server": map[string]interface{}{
            "port": 8080,
        },
        "db": map[string]interface{}{
            "host": "localhost",
            "port": 3306,
        },
    }),
)
```

## 配置获取

### 基本获取

```go
// 字符串
host := cfg.GetString("db.host", "localhost")

// 整数
port := cfg.GetInt("db.port", 3306)

// 布尔
debug := cfg.GetBool("debug", false)

// 浮点数
rate := cfg.GetFloat64("rate", 0.5)

// 字符串数组
hosts := cfg.GetStringSlice("hosts", []string{"localhost"})
```

### 结构体解析

```go
type DatabaseConfig struct {
    Host     string `yaml:"host"`
    Port     int    `yaml:"port"`
    Name     string `yaml:"name"`
    User     string `yaml:"user"`
    Password string `yaml:"password"`
}

var dbConfig DatabaseConfig
cfg.Unmarshal("db", &dbConfig)
```

### 嵌套获取

```go
host := cfg.GetString("db.host", "localhost")
port := cfg.GetInt("db.port", 3306)
```

## 全局配置

```go
// 初始化全局配置（可通过 Option 传入多个配置源）
config.Init(
    config.WithFile("config.yaml"),
    config.WithEnv("APP_"),
)

// 全局获取
host := config.GetString("db.host")
port := config.GetInt("db.port")
```

## 兼容性说明

- 旧版本中的 `config.Get()` 已不适用，请使用 `config.GetString/GetInt/GetBool` 等类型安全方法
- 环境变量前缀默认为 `APP_`，可通过 `WithEnv()` 自定义

## 错误处理

`Load/LoadApp/LoadFile` 在任一配置源加载失败时会返回错误（多个失败会聚合返回）。建议在启动阶段强校验，避免带着不完整配置继续运行。

```go
cfg, err := config.LoadApp()
if err != nil {
    // 配置加载失败，应该立即退出
    panic(fmt.Sprintf("配置加载失败: %v", err))
}
```

## 完整示例

```go
package main

import (
    "fmt"
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/config"
)

type AppConfig struct {
    Server ServerConfig `yaml:"server"`
    DB     DBConfig     `yaml:"db"`
    Redis  RedisConfig  `yaml:"redis"`
}

type ServerConfig struct {
    Port int    `yaml:"port"`
    Mode string `yaml:"mode"`
}

type DBConfig struct {
    Host     string `yaml:"host"`
    Port     int    `yaml:"port"`
    Name     string `yaml:"name"`
    User     string `yaml:"user"`
    Password string `yaml:"password"`
}

type RedisConfig struct {
    Host string `yaml:"host"`
    Port int    `yaml:"port"`
    DB   int    `yaml:"db"`
}

func main() {
    // 加载配置
    cfg, err := config.LoadApp()
    if err != nil {
        panic(err)
    }
    
    // 解析配置
    var appConfig AppConfig
    cfg.Unmarshal("", &appConfig)
    
    // 或单独获取
    serverPort := cfg.GetInt("server.port", 8080)
    dbHost := cfg.GetString("db.host", "localhost")
    
    r := gin.Default()
    r.Run(fmt.Sprintf(":%d", serverPort))
}
```
