# 优雅关闭

gint 提供优雅关闭功能，支持信号处理和资源清理。

## 概述

优雅关闭特性：
- 信号处理（SIGINT/SIGTERM）
- 关闭钩子（Shutdown Hooks）
- 超时控制
- 健康检查联动

## 基本使用

```go
import "github.com/ink-yht-code/gint/server"

func main() {
    r := gin.Default()
    
    // 业务路由...
    
    // 创建服务器
    srv := server.New(":8080", r)
    
    // 运行（自动处理优雅关闭）
    srv.Run()
}
```

## 关闭钩子

```go
srv := server.New(":8080", r)

// 注册关闭钩子
srv.RegisterShutdownHook(func(ctx context.Context) error {
    // 关闭数据库连接
    return db.Close()
})

srv.RegisterShutdownHook(func(ctx context.Context) error {
    // 关闭Redis连接
    return redis.Close()
})

srv.RegisterShutdownHook(func(ctx context.Context) error {
    // 关闭消息队列
    return mq.Close()
})

srv.Run()
```

## 超时配置

```go
srv := server.New(":8080", r,
    server.WithShutdownTimeout(30*time.Second),
)

srv.Run()
```

## 工作流程

```
1. 收到 SIGINT/SIGTERM 信号
         ↓
2. 设置服务为不健康状态（健康检查失败）
         ↓
3. 停止接收新请求
         ↓
4. 等待现有请求完成（最多等待超时时间）
         ↓
5. 执行关闭钩子（逆序执行）
         ↓
6. 关闭服务器
```

## 配合健康检查

```go
import (
    "github.com/ink-yht-code/gint/server"
    "github.com/ink-yht-code/gint/middlewares/health"
)

func main() {
    r := gin.Default()
    
    // 健康检查
    health.Health(r)
    
    // 业务路由...
    
    srv := server.New(":8080", r)
    
    // 关闭时设置不健康
    srv.RegisterShutdownHook(func(ctx context.Context) error {
        health.SetNotReady()
        return nil
    })
    
    srv.Run()
}
```

## 完整示例

```go
package main

import (
    "context"
    "time"
    
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/server"
    "github.com/ink-yht-code/gint/middlewares/health"
)

var (
    db    *sql.DB
    redis *redis.Client
)

func main() {
    // 初始化资源
    db = initDB()
    redis = initRedis()
    
    r := gin.Default()
    
    // 健康检查
    health.Health(r)
    
    // 业务路由
    r.GET("/api/users", GetUsers)
    
    // 创建服务器
    srv := server.New(":8080", r,
        server.WithShutdownTimeout(30*time.Second),
    )
    
    // 注册关闭钩子
    srv.RegisterShutdownHook(func(ctx context.Context) error {
        // 设置不健康
        health.SetNotReady()
        return nil
    })
    
    srv.RegisterShutdownHook(func(ctx context.Context) error {
        // 关闭数据库
        return db.Close()
    })
    
    srv.RegisterShutdownHook(func(ctx context.Context) error {
        // 关闭Redis
        return redis.Close()
    })
    
    // 运行
    srv.Run()
}
```
