# 消息队列（MQ）

gint 提供统一的消息队列抽象层，参考 mq-api 的接口设计，完全自主实现，不引入外部 MQ 抽象库。
支持 Kafka、RabbitMQ 和内存（测试用）三种后端。

## 核心接口

```go
// MQ 顶层工厂，负责 topic 管理和创建生产者/消费者
type MQ interface {
    CreateTopic(ctx context.Context, topic string, partitions int) error
    DeleteTopics(ctx context.Context, topics ...string) error
    Producer(topic string) (Producer, error)
    Consumer(topic string, groupID string) (Consumer, error)
    Close() error
}

// Producer 生产者，可并发使用
type Producer interface {
    Send(ctx context.Context, msg *Message) (*ProducerResult, error)
    SendWithPartition(ctx context.Context, msg *Message, partition int32) (*ProducerResult, error)
    Close() error
}

// Consumer 消费者，可并发使用
type Consumer interface {
    Consume(ctx context.Context) (*Message, error)          // 阻塞获取单条
    ConsumeChan(ctx context.Context) (<-chan *Message, error) // channel 方式
    Close() error
}
```

## Kafka

```go
import (
    "github.com/ink-yht-code/gint/mq/kafka"
)

m, err := kafka.NewMQ([]string{"localhost:9092"}, nil)
defer m.Close()

_ = m.CreateTopic(ctx, "orders", 3) // 3 个分区

// 生产
p, _ := m.Producer("orders")
p.Send(ctx, &mq.Message{
    Key:   []byte("order-123"),
    Value: []byte(`{"id":"123","status":"created"}`),
})

// 指定分区发送
p.SendWithPartition(ctx, msg, 2)

// 消费（阻塞）
c, _ := m.Consumer("orders", "payment-svc")
for {
    msg, err := c.Consume(ctx)
    // 处理 msg...
}

// 消费（channel 方式，适合 select）
ch, _ := c.ConsumeChan(ctx)
for msg := range ch {
    // 处理 msg...
}
```

## RabbitMQ

RabbitMQ 中 topic → routing key，groupID → queue name（同一 queue 多消费者竞争消费）。

```go
import (
    "github.com/ink-yht-code/gint/mq/rabbitmq"
)

m, err := rabbitmq.NewMQ(rabbitmq.RabbitMQConfig{
    URL:          "amqp://guest:guest@localhost:5672/",
    Exchange:     "events",
    ExchangeType: "topic",
    Durable:      true,
})
defer m.Close()

p, _ := m.Producer("order.created")
p.Send(ctx, &mq.Message{Value: []byte(`{"id":"123"}`)})

c, _ := m.Consumer("order.created", "payment-queue")
msg, _ := c.Consume(ctx)
```

## 内存（测试用）

无外部依赖，适合单元测试。

```go
import (
    "github.com/ink-yht-code/gint/mq/memory"
)

m := memory.NewMQ()
defer m.Close()

_ = m.CreateTopic(ctx, "events", 3)
p, _ := m.Producer("events")
c, _ := m.Consumer("events", "group-a")

p.Send(ctx, &mq.Message{Value: []byte("hello")})
msg, _ := c.Consume(ctx)
```

## 接入日志系统

```go
import (
    "github.com/ink-yht-code/gint/logger"
    "github.com/ink-yht-code/gint/mq/kafka"
)

m, _ := kafka.NewMQ([]string{"localhost:9092"}, nil)
p, _ := m.Producer("logs")

writer := logger.NewMQLogWriter(logger.MQLogWriterConfig{
    Producer:      logger.NewMQProducerAdapter(p, "logs"),
    Topic:         "logs",
    Service:       "order-service",
    BufferSize:    1000,
    BatchSize:     100,
    FlushInterval: 100 * time.Millisecond,
})
defer writer.Close()

logger.SetDBLogWriter(writer)
// 之后 logger.Info/Error 等会异步发送到 Kafka
```
