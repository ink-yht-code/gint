# 错误处理

gint 提供统一的错误码和错误处理机制，支持业务错误、系统错误、参数校验错误。

## 兼容性说明

- 旧版本中的 `Error` 结构已改为 `BizError`
- 旧版本中的 `NewError()` 已改为 `NewBizError()`
- 错误响应格式统一为 `{code, msg, data}`

## 概述

错误处理核心组件：
- **BizError** - 业务错误
- **Code** - 统一错误码
- **Handler包装器** - 自动处理错误响应

## 错误码定义

### 系统错误码

```go
const (
    CodeSuccess       = 0    // 成功
    CodeBadRequest    = 400  // 参数错误
    CodeUnauthorized  = 401  // 未授权
    CodeForbidden     = 403  // 禁止访问
    CodeNotFound      = 404  // 资源不存在
    CodeMethodNotAllowed = 405 // 方法不允许
    CodeConflict      = 409  // 冲突
    CodeTooManyRequests = 429 // 请求过多
    CodeInternalError = 500  // 内部错误
    CodeNotImplemented = 501 // 未实现
    CodeBadGateway    = 502  // 网关错误
    CodeServiceUnavailable = 503 // 服务不可用
)
```

### 自定义错误码

建议从 1000 开始定义业务错误码：

```go
const (
    // 用户相关 1000-1999
    CodeUserNotFound    = 1001
    CodeUserDisabled    = 1002
    CodePasswordWrong   = 1003
    CodeUserExists      = 1004
    
    // 订单相关 2000-2999
    CodeOrderNotFound   = 2001
    CodeOrderCanceled   = 2002
    CodeOrderPaid       = 2003
    
    // 商品相关 3000-3999
    CodeProductNotFound = 3001
    CodeProductOffShelf = 3002
    CodeStockNotEnough  = 3003
)
```

## BizError 业务错误

### 创建业务错误

```go
import "github.com/ink-yht-code/gint"

// 基本创建
err := gint.NewBizError(1001, "用户不存在")

// 带原因
err := gint.NewBizError(1001, "用户不存在").WithCause(dbErr)

// 格式化消息
err := gint.NewBizErrorf(1001, "用户 %s 不存在", userId)
```

### BizError 结构

```go
type BizError struct {
    Code  int    // 错误码
    Msg   string // 错误消息
    Cause error  // 原始错误
}
```

### 使用示例

```go
func (s *UserService) GetById(id int64) (*User, error) {
    user, err := s.repo.FindById(id)
    if err != nil {
        if errors.Is(err, gorm.ErrRecordNotFound) {
            return nil, gint.NewBizError(CodeUserNotFound, "用户不存在")
        }
        return nil, gint.NewBizError(CodeInternalError, "查询失败").WithCause(err)
    }
    
    if !user.Enabled {
        return nil, gint.NewBizError(CodeUserDisabled, "用户已禁用")
    }
    
    return user, nil
}
```

## Handler中的错误处理

### 返回错误

```go
r.GET("/users/:id", gint.U(func(c *gin.Context, req GetReq) (gint.Result, error) {
    user, err := userService.GetById(req.ID)
    if err != nil {
        // 返回业务错误
        return gint.Result{}, err
    }
    
    return gint.Result{Data: user}, nil
}))
```

### 错误响应格式

```json
{
    "code": 1001,
    "msg": "用户不存在",
    "data": null
}
```

## 错误判断

### Is 判断错误码

```go
err := userService.GetById(id)

if gint.IsErrorCode(err, CodeUserNotFound) {
    // 用户不存在
}

if gint.IsErrorCode(err, CodeUserDisabled) {
    // 用户已禁用
}
```

### 判断业务错误

```go
var bizErr *gint.BizError
if errors.As(err, &bizErr) {
    fmt.Println(bizErr.Code)
    fmt.Println(bizErr.Msg)
}
```

## 错误码注册

### 注册错误码

```go
// 注册错误码描述
gint.RegisterCode(CodeUserNotFound, "用户不存在", "用户ID不存在或已删除")
gint.RegisterCode(CodeUserDisabled, "用户已禁用", "用户账号已被禁用，请联系管理员")
```

### 获取错误码描述

```go
desc := gint.GetCodeDesc(CodeUserNotFound)
// desc = "用户ID不存在或已删除"
```

## 统一错误处理中间件

```go
func ErrorHandler() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Next()
        
        // 处理最后出现的错误
        if len(c.Errors) > 0 {
            err := c.Errors.Last().Err
            
            var bizErr *gint.BizError
            if errors.As(err, &bizErr) {
                c.JSON(200, gin.H{
                    "code": bizErr.Code,
                    "msg":  bizErr.Msg,
                    "data": nil,
                })
                return
            }
            
            // 未知错误
            c.JSON(500, gin.H{
                "code": 500,
                "msg":  "服务器内部错误",
                "data": nil,
            })
        }
    }
}
```

### 2. 错误定义集中管理

```go
// internal/errors/errors.go
package errors

import "github.com/ink-yht-code/gint"

const (
    CodeUserNotFound  = 1001
    CodeUserDisabled  = 1002
    CodePasswordWrong = 1003
)

var (
    ErrUserNotFound  = gint.NewBizError(CodeUserNotFound, "用户不存在")
    ErrUserDisabled  = gint.NewBizError(CodeUserDisabled, "用户已禁用")
    ErrPasswordWrong = gint.NewBizError(CodePasswordWrong, "密码错误")
)
```

### 3. 错误包装

```go
func (s *UserService) Login(email, password string) (*User, error) {
    user, err := s.repo.FindByEmail(email)
    if err != nil {
        return nil, gint.NewBizError(CodeUserNotFound, "用户不存在").WithCause(err)
    }
    
    if !s.checkPassword(user.Password, password) {
        return nil, gint.ErrPasswordWrong
    }
    
    return user, nil
}
```

### 4. 错误日志

```go
func (s *UserService) GetById(id int64) (*User, error) {
    user, err := s.repo.FindById(id)
    if err != nil {
        // 记录原始错误
        logger.Error("查询用户失败", 
            zap.Int64("id", id),
            zap.Error(err))
        
        // 返回业务错误
        return nil, gint.NewBizError(CodeUserNotFound, "用户不存在")
    }
    return user, nil
}
```

## 完整示例

```go
package main

import (
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint"
)

// 错误码定义
const (
    CodeUserNotFound  = 1001
    CodeUserDisabled  = 1002
    CodePasswordWrong = 1003
)

// 预定义错误
var (
    ErrUserNotFound  = gint.NewBizError(CodeUserNotFound, "用户不存在")
    ErrUserDisabled  = gint.NewBizError(CodeUserDisabled, "用户已禁用")
    ErrPasswordWrong = gint.NewBizError(CodePasswordWrong, "密码错误")
)

type LoginReq struct {
    Email    string `json:"email" validate:"required,email"`
    Password string `json:"password" validate:"required,min=6"`
}

func main() {
    r := gin.Default()
    
    r.POST("/login", gint.B(func(c *gin.Context, req LoginReq) (gint.Result, error) {
        user, err := userService.Login(req.Email, req.Password)
        if err != nil {
            // 自动返回错误响应
            return gint.Result{}, err
        }
        
        token, _ := jwt.Generate(user)
        
        return gint.Result{
            Data: gin.H{
                "token": token,
                "user":  user,
            },
        }, nil
    }))
    
    r.Run(":8080")
}
```
