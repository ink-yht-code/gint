# 参数校验

`gint` 提供了结合请求绑定与规则校验的能力，适合在 Handler 层完成格式校验。

## 常见方式

最常见的方式是使用请求结构体配合包装器自动绑定：

```go
type CreateUserReq struct {
	Name  string `json:"name" binding:"required"`
	Email string `json:"email" binding:"required,email"`
}

r.POST("/users", gint.B(func(ctx *gctx.Context, req CreateUserReq) (gint.Result, error) {
	return gint.Success("", req), nil
}))
```

## 校验器构建器

很多当前项目会使用 `ValidatorBuilder` 动态组织规则：

```go
vb := gint.NewValidatorBuilder()
vb.Field("phone", req.Phone).AddRule(gint.Required()).AddRule(gint.Mobile())
vb.Field("password", req.Password).AddRule(gint.Password())
v := vb.Validate()
if !v.IsValid() {
	return gint.InvalidParam(v.GetFirstError()), nil
}
```

## 常用规则

- `gint.Required()`
- `gint.Mobile()`
- `gint.Password()`
- `gint.LengthRange(min, max)`

## 手动示例

```go
vb := gint.NewValidatorBuilder()
vb.Field("code", req.Code).AddRule(gint.Required()).AddRule(gint.LengthRange(4, 6))
v := vb.Validate()
if !v.IsValid() {
	return gint.InvalidParam(v.GetFirstError()), nil
}
```

## 建议

- 简单场景优先使用结构体绑定
- 需要动态规则时使用 `ValidatorBuilder`
- 格式校验放在 Handler 层，业务校验放在 Service 层
