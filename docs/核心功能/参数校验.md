# 参数校验

gint 提供基于 `go-playground/validator` 的参数校验功能，支持链式API和自定义校验规则。

## 概述

参数校验特性：
- 自动校验请求参数
- 丰富的内置校验规则
- 支持自定义校验
- 中文错误消息

## 内置校验规则

### 字符串校验

| 规则 | 说明 | 示例 |
|------|------|------|
| `required` | 必填 | `validate:"required"` |
| `min=10` | 最小长度 | `validate:"min=10"` |
| `max=100` | 最大长度 | `validate:"max=100"` |
| `len=10` | 固定长度 | `validate:"len=10"` |
| `email` | 邮箱格式 | `validate:"email"` |
| `url` | URL格式 | `validate:"url"` |
| `uri` | URI格式 | `validate:"uri"` |
| `alpha` | 仅字母 | `validate:"alpha"` |
| `alphanum` | 字母数字 | `validate:"alphanum"` |
| `numeric` | 数字 | `validate:"numeric"` |
| `lowercase` | 小写 | `validate:"lowercase"` |
| `uppercase` | 大写 | `validate:"uppercase"` |
| `contains=foo` | 包含子串 | `validate:"contains=foo"` |
| `excludes=bar` | 排除子串 | `validate:"excludes=bar"` |
| `startswith=foo` | 以...开头 | `validate:"startswith=foo"` |
| `endswith=bar` | 以...结尾 | `validate:"endswith=bar"` |

### 数值校验

| 规则 | 说明 | 示例 |
|------|------|------|
| `min=10` | 最小值 | `validate:"min=10"` |
| `max=100` | 最大值 | `validate:"max=100"` |
| `gte=0` | 大于等于 | `validate:"gte=0"` |
| `lte=100` | 小于等于 | `validate:"lte=100"` |
| `gt=0` | 大于 | `validate:"gt=0"` |
| `lt=100` | 小于 | `validate:"lt=100"` |
| `oneof=1 2 3` | 枚举值 | `validate:"oneof=1 2 3"` |

### 数组校验

| 规则 | 说明 | 示例 |
|------|------|------|
| `min=1` | 最少元素 | `validate:"min=1"` |
| `max=10` | 最多元素 | `validate:"max=10"` |
| `len=5` | 固定长度 | `validate:"len=5"` |
| `unique` | 元素唯一 | `validate:"unique"` |
| `dive` | 深入校验 | `validate:"dive,required"` |

### 其他校验

| 规则 | 说明 | 示例 |
|------|------|------|
| `ip` | IP地址 | `validate:"ip"` |
| `ipv4` | IPv4地址 | `validate:"ipv4"` |
| `ipv6` | IPv6地址 | `validate:"ipv6"` |
| `json` | JSON格式 | `validate:"json"` |
| `file` | 文件路径 | `validate:"file"` |
| `dir` | 目录路径 | `validate:"dir"` |
| `datetime=2006-01-02` | 日期格式 | `validate:"datetime=2006-01-02"` |

## 使用方式

### 结构体标签

```go
type CreateUserReq struct {
    Name     string `json:"name" validate:"required,min=2,max=50"`
    Email    string `json:"email" validate:"required,email"`
    Password string `json:"password" validate:"required,min=8,max=32"`
    Age      int    `json:"age" validate:"gte=0,lte=150"`
    Role     string `json:"role" validate:"required,oneof=admin user guest"`
    Phone    string `json:"phone" validate:"omitempty,len=11"`
    Avatar   string `json:"avatar" validate:"omitempty,url"`
}
```

### 链式API

```go
import "github.com/ink-yht-code/gint"

// 创建校验器
v := gint.NewValidator()

// 链式校验
err := v.Validate(value).
    Required("名称不能为空").
    MinLength(2, "名称最少2个字符").
    MaxLength(50, "名称最多50个字符").
    Error()

if err != nil {
    // 处理校验错误
}
```

### 手动校验

```go
import "github.com/ink-yht-code/gint"

func Handler(c *gin.Context) {
    var req CreateUserReq
    if err := c.ShouldBindJSON(&req); err != nil {
        c.JSON(400, gin.H{"code": 400, "msg": "参数格式错误"})
        return
    }
    
    // 手动校验
    if err := gint.ValidateStruct(req); err != nil {
        c.JSON(400, gin.H{
            "code": 400,
            "msg":  "参数校验失败",
            "data": gint.FormatValidationErrors(err),
        })
        return
    }
    
    // 业务处理...
}
```

## 自定义校验

### 注册自定义校验规则

```go
import "github.com/ink-yht-code/gint"

func init() {
    // 注册手机号校验
    gint.RegisterValidation("mobile", func(fl validator.FieldLevel) bool {
        mobile := fl.Field().String()
        matched, _ := regexp.MatchString(`^1[3-9]\d{9}$`, mobile)
        return matched
    })
    
    // 注册用户名校验（字母开头，允许字母数字下划线）
    gint.RegisterValidation("username", func(fl validator.FieldLevel) bool {
        username := fl.Field().String()
        matched, _ := regexp.MatchString(`^[a-zA-Z][a-zA-Z0-9_]{2,19}$`, username)
        return matched
    })
}
```

### 使用自定义校验

```go
type RegisterReq struct {
    Username string `json:"username" validate:"required,username"`
    Mobile   string `json:"mobile" validate:"required,mobile"`
    Email    string `json:"email" validate:"required,email"`
}
```

### 带参数的自定义校验

```go
// 注册带参数的校验规则
gint.RegisterValidation("minage", func(fl validator.FieldLevel) bool {
    // 获取参数
    minAge := fl.Param() // 例如 "minage=18" 参数为 "18"
    age := fl.Field().Int()
    
    minAgeInt, _ := strconv.Atoi(minAge)
    return age >= int64(minAgeInt)
})

type CreatePlayerReq struct {
    Name string `json:"name" validate:"required"`
    Age  int    `json:"age" validate:"minage=18"` // 年龄必须>=18
}
```

## 校验错误处理

### 错误格式化

Handler包装器自动格式化校验错误：

```json
{
    "code": 400,
    "msg": "参数校验失败",
    "data": {
        "name": "名称长度必须在2-50之间",
        "email": "邮箱格式不正确",
        "password": "密码长度必须在8-32之间"
    }
}
```

### 手动格式化

```go
if err := gint.ValidateStruct(req); err != nil {
    // 获取格式化的错误
    errors := gint.FormatValidationErrors(err)
    // errors = map[string]string{"name": "名称不能为空", ...}
}
```

## 条件校验

### omitempty

字段为空时跳过校验：

```go
type UpdateProfileReq struct {
    Nickname string `json:"nickname" validate:"omitempty,min=2,max=50"`
    Avatar   string `json:"avatar" validate:"omitempty,url"`
    Email    string `json:"email" validate:"omitempty,email"`
}
```

### required_with

当指定字段存在时必填：

```go
type CreateOrderReq struct {
    PaymentMethod string  `json:"payment_method" validate:"required,oneof=alipay wechat"`
    CouponCode    string  `json:"coupon_code" validate:"omitempty"`
    CouponAmount  float64 `json:"coupon_amount" validate:"required_with=CouponCode,gt=0"`
}
```

### required_without

当指定字段不存在时必填：

```go
type LoginReq struct {
    Email    string `json:"email" validate:"required_without=Mobile,email"`
    Mobile   string `json:"mobile" validate:"required_without=Email,mobile"`
    Password string `json:"password" validate:"required"`
}
```

## 嵌套校验

### 嵌套结构体

```go
type Address struct {
    Province string `json:"province" validate:"required"`
    City     string `json:"city" validate:"required"`
    Detail   string `json:"detail" validate:"required,min=5"`
}

type CreateUserReq struct {
    Name    string  `json:"name" validate:"required"`
    Address Address `json:"address" validate:"required"`
}
```

### 数组元素校验

```go
type CreateOrderReq struct {
    Items []OrderItem `json:"items" validate:"required,min=1,dive"`
}

type OrderItem struct {
    ProductId int64 `json:"product_id" validate:"required,gt=0"`
    Quantity  int   `json:"quantity" validate:"required,gte=1"`
    Price     float64 `json:"price" validate:"required,gt=0"`
}
```

### Map校验

```go
type ConfigReq struct {
    Settings map[string]string `json:"settings" validate:"required,dive,keys,min=1,max=50,endkeys,required,min=1,max=200"`
}
```

## 中文错误消息

gint 默认使用中文错误消息：

| 规则 | 中文消息 |
|------|---------|
| `required` | 不能为空 |
| `min` | 长度/值不能小于{param} |
| `max` | 长度/值不能大于{param} |
| `email` | 邮箱格式不正确 |
| `url` | URL格式不正确 |

### 自定义错误消息

```go
type CreateUserReq struct {
    Name string `json:"name" validate:"required,min=2,max=50" msg:"名称:必填,长度2-50"`
}

// 或注册自定义消息
gint.RegisterValidationMessages(map[string]string{
    "mobile": "手机号格式不正确",
    "username": "用户名必须以字母开头，只能包含字母数字下划线",
})
```

### 1. 校验规则完整

```go
type CreateUserReq struct {
    Name     string `json:"name" validate:"required,min=2,max=50"`
    Email    string `json:"email" validate:"required,email"`
    Password string `json:"password" validate:"required,min=8,max=32"`
    Phone    string `json:"phone" validate:"omitempty,len=11"`
    Age      int    `json:"age" validate:"gte=0,lte=150"`

```

### 2. 复用校验规则

```go
// 公共字段
type BaseReq struct {
    Page     int `form:"page" validate:"gte=1"`
    PageSize int `form:"page_size" validate:"gte=1,lte=100"`
}

type ListUsersReq struct {
    BaseReq
    Keyword string `form:"keyword"`
    Status  int    `form:"status" validate:"oneof=0 1 2"`
}
```

### 3. 业务校验与格式校验分离

```go
type CreateUserReq struct {

        return nil, gint.NewBizError(1004, "邮箱已被注册")
    }
    
    // 创建用户...
}
```

## 完整示例

```go
package main

import (
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint"
)

// 自定义校验规则
func init() {
    gint.RegisterValidation("mobile", func(fl validator.FieldLevel) bool {
        mobile := fl.Field().String()
        matched, _ := regexp.MatchString(`^1[3-9]\d{9}$`, mobile)
        return matched
    })
}

type RegisterReq struct {
    Username string `json:"username" validate:"required,min=3,max=20,alphanum"`
    Password string `json:"password" validate:"required,min=8,max=32"`
    Email    string `json:"email" validate:"required,email"`
    Mobile   string `json:"mobile" validate:"required,mobile"`
    Age      int    `json:"age" validate:"gte=0,lte=150"`
}

func main() {
    r := gin.Default()
    
    r.POST("/register", gint.B(func(c *gin.Context, req RegisterReq) (gint.Result, error) {
        // req 已自动校验
        
        user, err := userService.Register(req)
        if err != nil {
            return gint.Result{}, err
        }
        
        return gint.Result{
            Msg:  "注册成功",
            Data: user,
        }, nil
    }))
    
    r.Run(":8080")
}
```
