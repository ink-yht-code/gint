# 负载均衡

负载均衡模块提供了多种负载均衡算法，支持服务实例的选择。

## 功能特性

- 支持多种负载均衡算法（轮询、加权轮询、随机、最少连接、一致性哈希）
- 支持服务实例的动态更新
- 与服务注册发现集成
- 与Context集成，自动传递追踪ID

## 使用示例

```go
package main

import (
    "github.com/ink-yht-code/gint/loadbalance"
)

func main() {
    // 创建轮询负载均衡器
    lb := loadbalance.NewRoundRobin()
    
    // 添加服务实例
    lb.Add("192.168.1.100:8080")
    lb.Add("192.168.1.101:8080")
    lb.Add("192.168.1.102:8080")
    
    // 选择服务实例
    instance, err := lb.Select()
    if err != nil {
        // 处理错误
    }
    
    // 使用实例
    fmt.Println("选择的实例:", instance)
}
```

## 接口定义

```go
type LoadBalancer interface {
    // Add 添加服务实例
    Add(address string, weight ...int)
    
    // Remove 移除服务实例
    Remove(address string)
    
    // Select 选择服务实例
    Select() (string, error)
    
    // SelectByKey 根据key选择实例（一致性哈希）
    SelectByKey(key string) (string, error)
    
    // Instances 获取所有实例
    Instances() []string
}
```
