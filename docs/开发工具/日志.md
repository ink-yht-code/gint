# 日志

`gint/logger` 基于 `zap` 封装，提供统一初始化、结构化字段、文件轮转、请求日志以及可选的数据库日志写入能力。

## 功能

- 支持 `debug`、`info`、`warn`、`error`
- 支持 `json`、`text` 两种格式
- 支持 `stdout`、`file`、`both` 三种输出方式
- 支持基础日志轮转
- 支持 `trace_id`、`user_id` 上下文字段
- 支持数据库日志写入器

## 快速开始

```go
package main

import (
	"github.com/ink-yht-code/gint/logger"
	"go.uber.org/zap"
)

func main() {
	err := logger.Init(logger.Config{
		Level:    "info",
		Format:   "text",
		Output:   "stdout",
		Filename: "./logs/app.log",
	})
	if err != nil {
		panic(err)
	}

	logger.Info("服务启动", zap.String("addr", ":8080"))
	logger.Warn("慢请求", zap.String("path", "/users/me"))
}
```

## 配置

```go
type Config struct {
	Level      string
	Format     string
	Output     string
	Filename   string
	MaxSize    int
	MaxBackups int
	MaxAge     int
	Compress   bool
	EnableDB   bool
	DBLevel    string
}
```

## 上下文日志

```go
lc := logger.WithTraceAndUserID("trace-123", "user-001")
lc.Info("请求已接收")
lc.Error("请求处理失败")
```

## 请求日志中间件

```go
r.Use(logger.RequestLogger())
```

这个中间件会：

- 自动补充 `X-Request-ID`
- 记录请求开始和结束
- 输出路径、方法、状态码、耗时、客户端 IP 等字段

## 建议

- 本地开发建议使用 `text + stdout`
- 生产环境建议使用 `json + both` 或 `json + file`
- 接入日志平台时建议优先使用 `json`
