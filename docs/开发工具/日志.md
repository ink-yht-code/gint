# 日志系统

日志系统基于zap实现，提供结构化日志输出和多种输出方式。

## 功能特性

- 基于zap的高性能日志
- 支持多种输出方式（控制台、文件、MQ等）
- 支持日志级别
- 支持结构化日志
- 与Context集成，自动传递追踪ID

## 使用示例

```go
package main

import (
    "github.com/ink-yht-code/gint/logger"
    "go.uber.org/zap"
)

func main() {
    // 初始化日志
    err := logger.Init(logger.Config{
        Level:  "info",
        Output: "console",
        File:   "logs/app.log",
    })
    if err != nil {
        // 处理错误
    }
    
    // 记录日志
    logger.Info("服务启动", zap.String("address", ":8080"))
    logger.Error("服务错误", zap.Error(err))
    logger.Debug("调试信息", zap.Any("data", "value"))
    logger.Warn("警告信息", zap.String("key", "value"))
    logger.Fatal("致命错误", zap.Error(err))
}
```

## 配置选项

```go
type Config struct {
    // Level 日志级别（debug, info, warn, error, fatal）
    Level string
    
    // Output 输出方式（console, file, mq）
    Output string
    
    // File 日志文件路径（当Output为file时生效）
    File string
    
    // MQ 消息队列配置（当Output为mq时生效）
    MQ MQConfig
    
    // MaxSize 单个日志文件最大大小（MB）
    MaxSize int
    
    // MaxBackups 保留的日志文件数量
    MaxBackups int
    
    // MaxAge 日志文件保留天数
    MaxAge int
    
    // Compress 是否压缩日志文件
    Compress bool
}
```

## 与Context集成

```go
func handler(ctx *gint.Context) {
    // 自动添加追踪ID
    logger.Info("处理请求", zap.String("path", ctx.Request.URL.Path))
}
```

## 日志格式

默认日志格式为JSON：

```json
{
    "level": "info",
    "ts": 1711234567,
    "caller": "main.go:20",
    "msg": "服务启动",
    "address": ":8080",
    "trace_id": "abc123"
}
```
