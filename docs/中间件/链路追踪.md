# 链路追踪

`middlewares/trace` 提供轻量级请求追踪能力，通常基于请求 ID 或 trace ID。

## 基本使用

```go
import "github.com/ink-yht-code/gint/middlewares/trace"

r.Use(trace.Middleware())
```

## 常见请求头

- `X-Trace-ID`

## 下游透传

调用下游服务时，应保留追踪 Header，方便跨服务日志关联。

```go
req, _ := http.NewRequest(http.MethodGet, "http://downstream/api", nil)
trace.InjectGctx(ctx, req)
```

## 建议

- 即使没有完整 OpenTelemetry，也建议保留 trace ID
- 结构化日志中尽量输出 trace ID
