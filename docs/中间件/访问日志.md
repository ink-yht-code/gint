# 访问日志中间件

访问日志中间件用于记录所有HTTP请求的详细信息，帮助监控和分析服务运行状态。

## 兼容性说明

- 当前版本推荐使用 Builder 方式构建中间件
- 旧示例中的 `accesslog.NewMiddleware()` 已不再作为主入口

## 功能特性

- 结构化日志输出（JSON格式）
- 记录请求时间、响应时间、状态码等
- 支持自定义日志格式
- 与zap日志系统集成

## 使用示例

```go
package main

import (
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/middlewares/accesslog"
)

func main() {
    r := gin.Default()
    
    // 使用访问日志中间件
    r.Use(accesslog.NewBuilder(accesslog.ZapLogFunc()).Build())
    
    r.GET("/ping", func(c *gin.Context) {
        c.JSON(200, gin.H{
            "message": "pong",
        })
    })
    
    r.Run(":8080")
}
```

## 日志格式

默认日志格式包含以下字段：

```json
{
    "level": "info",
    "ts": 1711234567,
    "caller": "accesslog/middleware.go:42",
    "msg": "HTTP请求",
    "method": "GET",
    "path": "/ping",
    "status": 200,
    "duration": 12345,
    "client_ip": "192.168.1.1",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/123.0.0.0 Safari/537.36"
}
```

## Builder 配置选项

```go
b := accesslog.NewBuilder(accesslog.ZapLogFunc()).
    WithReqBody(true).
    WithRespBody(true).
    WithMaxBodyLength(2048)

r.Use(b.Build())
```
