# 访问日志

`middlewares/accesslog` 提供结构化 HTTP 请求日志。

## 基本使用

```go
import "github.com/ink-yht-code/gint/middlewares/accesslog"

r.Use(accesslog.NewBuilder(accesslog.ZapLogFunc()).
	WithReqBody(false).
	WithRespBody(false).
	WithMaxBodyLength(1024).
	Build())
```

## 构建器配置

```go
b := accesslog.NewBuilder(accesslog.ZapLogFunc()).
	WithReqBody(true).
	WithRespBody(true).
	WithMaxBodyLength(2048)

r.Use(b.Build())
```

## 常见字段

- method
- path
- query
- ip
- status
- duration_ms
- user_agent

## 建议

- 生产环境不要默认开启完整请求体和响应体日志
- `MaxBodyLength` 要设置合理上限
- 有链路 ID 时建议一起写入结构化日志
