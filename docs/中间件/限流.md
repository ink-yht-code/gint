# 限流

gint 提供限流中间件，支持基于 IP 和用户的限流策略。

## 兼容性说明

- 旧版本中的 `ratelimit.New()` 已不适用，请使用 `ratelimit.Middleware()`
- 旧版本中的 `Store` 接口已重构，Redis 存储需使用 `ratelimit.NewRedisStore()`

## 概述

限流中间件特性：
- 基于IP限流
- 基于用户ID限流
- 滑动窗口算法
- 支持自定义限流策略

## 基本使用

### 默认配置

```go
import "github.com/ink-yht-code/gint/middlewares/ratelimit"

// 默认：每秒100请求，基于IP
r.Use(ratelimit.Middleware())
```

### 自定义配置

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:       100,              // 每秒请求数
    Burst:      200,              // 突发容量
    KeyBy:      ratelimit.ByIP,   // 限流维度：IP/用户
    Store:      nil,              // 存储后端（nil=内存）
}))
```

## 配置选项

```go
type Config struct {
    // Rate 每秒允许的请求数
    Rate int
    
    // Burst 突发容量
    Burst int
    
    // KeyBy 限流维度
    // ByIP    - 基于IP限流
    // ByUser  - 基于用户ID限流
    KeyBy KeyBy
    
    // Store 存储后端
    // nil - 内存存储（单机）
    // Redis - 分布式限流
    Store Store
    
    // KeyFunc 自定义Key函数
    KeyFunc func(c *gin.Context) string
    
    // OnLimited 限流时的处理函数
    OnLimited func(c *gin.Context)
}
```

## 限流维度

### 基于IP限流

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:  100,  // 每IP每秒100请求
    Burst: 200,
    KeyBy: ratelimit.ByIP,
}))
```

### 基于用户限流

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:  50,   // 每用户每秒50请求
    Burst: 100,
    KeyBy: ratelimit.ByUser,
}))
```

### 自定义Key

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate: 100,
    KeyFunc: func(c *gin.Context) string {
        // 按路径+IP限流
        return c.FullPath() + ":" + c.ClientIP()
    },
}))
```

## 分布式限流

### Redis存储

```go
import (
    "github.com/ink-yht-code/gint/middlewares/ratelimit"
    "github.com/redis/go-redis/v9"
)

func main() {
    rdb := redis.NewClient(&redis.Options{
        Addr: "localhost:6379",
    })
    
    r.Use(ratelimit.Middleware(ratelimit.Config{
        Rate:  100,
        Burst: 200,
        KeyBy: ratelimit.ByIP,
        Store: ratelimit.NewRedisStore(rdb, "ratelimit:"),
    }))
}
```

## 限流响应

### 默认响应

```json
{
    "code": 429,
    "msg": "请求过多，请稍后再试",
    "data": null
}
```

### 自定义响应

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate: 100,
    OnLimited: func(c *gin.Context) {
        c.JSON(429, gin.H{
            "code": 429,
            "msg":  "访问过于频繁，请1秒后重试",
            "data": nil,
        })
        c.Abort()
    },
}))
```

## 完整示例

```go
package main

import (
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/middlewares/ratelimit"
    "github.com/redis/go-redis/v9"
)

func main() {
    r := gin.Default()
    
    // 全局限流
    r.Use(ratelimit.Middleware(ratelimit.Config{
        Rate:  1000, // 全局每秒1000请求
        Burst: 2000,
        KeyFunc: func(c *gin.Context) string {
            return "global"
        },
    }))
    
    // API限流
    api := r.Group("/api")
    api.Use(ratelimit.Middleware(ratelimit.Config{
        Rate:  100, // 每IP每秒100请求
        Burst: 200,
        KeyBy: ratelimit.ByIP,
    }))
    {
        api.GET("/data", GetData)
    }
    
    // 登录限流（更严格）
    r.POST("/login", ratelimit.Middleware(ratelimit.Config{
        Rate:  5,  // 每IP每秒5次登录尝试
        Burst: 10,
        KeyBy: ratelimit.ByIP,
        OnLimited: func(c *gin.Context) {
            c.JSON(429, gin.H{
                "code": 429,
                "msg":  "登录尝试过于频繁，请稍后再试",
            })
            c.Abort()
        },
    }), Login)
    
    r.Run(":8080")
}
```

## 最佳实践

### 1. 分层限流

```go
// 全局限流 - 保护整个服务
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:  10000,
    Burst: 20000,
    KeyFunc: func(c *gin.Context) string {
        return "global"
    },
}))

// 用户限流 - 保护单个用户
api := r.Group("/api")
api.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:  100,
    Burst: 200,
    KeyBy: ratelimit.ByUser,
}))

// 敏感操作限流 - 更严格
r.POST("/api/transfer", ratelimit.Middleware(ratelimit.Config{
    Rate:  10,
    Burst: 20,
    KeyBy: ratelimit.ByUser,
}), Transfer)
```

### 2. 分布式限流

```go
rdb := redis.NewClient(&redis.Options{
    Addr: "localhost:6379",
})

r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate:  100,
    Burst: 200,
    KeyBy: ratelimit.ByIP,
    Store: ratelimit.NewRedisStore(rdb, "ratelimit:"),
}))
```

### 3. 自定义限流策略

```go
// 按用户等级限流
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate: 100,
    KeyFunc: func(c *gin.Context) string {
        userID := c.GetString("user_id")
        userLevel := c.GetString("user_level")
        
        // VIP用户限流更宽松
        if userLevel == "vip" {
            return "vip:" + userID
        }
        return "normal:" + c.ClientIP()
    },
}))
```

### 4. 限流监控

```go
r.Use(ratelimit.Middleware(ratelimit.Config{
    Rate: 100,
    OnLimited: func(c *gin.Context) {
        // 记录限流事件
        logger.Warn("请求被限流",
            zap.String("ip", c.ClientIP()),
            zap.String("path", c.FullPath()),
        )
        
        c.JSON(429, gin.H{
            "code": 429,
            "msg":  "请求过于频繁",
        })
        c.Abort()
    },
}))
```
