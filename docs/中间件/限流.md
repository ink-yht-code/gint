# 限流

`middlewares/ratelimit` 提供请求限流能力。

## 当前构建器风格

```go
limiter := ratelimit.NewSlidingWindowLimiter(5, time.Minute)
r.Use(ratelimit.NewBuilder(limiter).Build())
```

## 常见用法

```go
sendCodeLimiter := ratelimit.NewBuilder(
	ratelimit.NewSlidingWindowLimiter(5, time.Minute),
).Build()

r.POST("/oauth2/code/send", sendCodeLimiter, handler)
```

## 建议

- 登录、发验证码、重置密码等接口应使用更严格的限制
- 普通读接口可以使用更宽松的限制
- 限流规则尽量靠近对应路由注册位置，便于维护
