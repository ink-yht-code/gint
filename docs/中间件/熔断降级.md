# 熔断降级

gint 提供熔断降级中间件，防止服务雪崩，支持自定义降级处理。

## 兼容性说明

- 旧示例中的 `WithConfig`、`WithOnStateChange` 已不适用于当前实现
- 请使用 `NewBuilder(config).WithKeyFunc(...).WithFallback(...).Build()`

## 概述

熔断降级特性：
- 三种状态：Closed、Open、Half-Open
- 可配置失败/成功阈值
- 支持自定义降级处理
- 支持按路径分组熔断

## 工作原理

```
         失败次数达到阈值
    ┌────────────────────────┐
    │                        ▼
┌───┴───┐              ┌─────────┐
│ Closed │─────────────▶│  Open   │
└───┬───┘              └────┬────┘
    ▲                       │
    │                       │ 超时后
    │ 成功次数达到阈值       ▼
    │                 ┌──────────┐
    └─────────────────│ Half-Open│
                      └──────────┘
                           │
                           │ 失败
                           ▼
                      返回 Open
```

## 基本使用

### 默认配置

```go
import "github.com/ink-yht-code/gint/middlewares/circuitbreaker"

// 默认：连续5次失败后熔断30秒
r.Use(circuitbreaker.Middleware())
```

### 带降级处理

```go
r.Use(circuitbreaker.WithFallback(func(c *gin.Context) {
    c.JSON(200, gin.H{
        "code": 0,
        "msg":  "服务降级",
        "data": nil,
    })
}))
```

### 自定义配置

```go
r.Use(circuitbreaker.Middleware(circuitbreaker.Config{
    FailureThreshold: 10,           // 连续失败10次触发熔断
    SuccessThreshold: 5,            // 半开状态连续成功5次恢复
    Timeout:          60*time.Second, // 熔断持续时间
    HalfOpenRequests: 1,            // 半开状态允许并发请求数
}))
```

## 当前版本 API

```go
b := circuitbreaker.NewBuilder(circuitbreaker.Config{
    FailureThreshold: 5,
    SuccessThreshold: 3,
    Timeout:          30 * time.Second,
    HalfOpenRequests: 1,
})

r.Use(
    b.WithKeyFunc(func(c *gin.Context) string {
        return c.FullPath() // 每个路径独立熔断
    }).WithFallback(func(c *gin.Context) {
        c.AbortWithStatusJSON(503, gin.H{
            "code": 503,
            "msg":  "服务暂时不可用",
        })
    }).Build(),
)
```

## 配置选项

```go
type Config struct {
    // FailureThreshold 连续失败次数阈值
    FailureThreshold int
    
    // SuccessThreshold 半开状态连续成功次数阈值
    SuccessThreshold int
    
    // Timeout 熔断持续时间
    Timeout time.Duration

    // HalfOpenRequests 半开状态允许并发请求数
    HalfOpenRequests int
}
```

## 按路径分组熔断

```go
b := circuitbreaker.NewBuilder(circuitbreaker.Config{
    FailureThreshold: 5,
    SuccessThreshold: 3,
    Timeout:          30 * time.Second,
    HalfOpenRequests: 1,
})

r.Use(
    b.
    WithKeyFunc(func(c *gin.Context) string {
        return c.FullPath() // 每个路径独立熔断
    }).
    WithFallback(func(c *gin.Context) {
        c.AbortWithStatusJSON(503, gin.H{
            "code": 503,
            "msg":  "服务暂时不可用",
        })
    }).
    Build(),
)
```

## 说明

- 半开状态现在会严格限制并发探测请求数（`HalfOpenRequests` 生效）
- 超阈值失败后进入 `Open`，超时后进入 `Half-Open`，成功达到阈值后恢复 `Closed`

## 客户端熔断

保护外部服务调用：

```go
import "github.com/ink-yht-code/gint/middlewares/circuitbreaker"

// 创建HTTP熔断器
breaker := circuitbreaker.NewHTTPBreaker(circuitbreaker.Config{
    FailureThreshold: 5,
    SuccessThreshold: 3,
    Timeout:          30*time.Second,
})

// 调用外部服务
err := breaker.Do(func() error {
    _, err := http.Get("http://external-service/api")
    return err
})
```

## 完整示例

```go
package main

import (
    "time"
    
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/middlewares/circuitbreaker"
)

func main() {
    r := gin.Default()

    b := circuitbreaker.NewBuilder(circuitbreaker.Config{
        FailureThreshold: 10,
        SuccessThreshold: 5,
        Timeout:          60 * time.Second,
        HalfOpenRequests: 1,
    })

    // 全局熔断
    r.Use(
        b.WithKeyFunc(func(c *gin.Context) string {
            return c.FullPath()
        }).WithFallback(func(c *gin.Context) {
            c.AbortWithStatusJSON(503, gin.H{
                "code": 503,
                "msg":  "服务暂时不可用，请稍后重试",
            })
        }).Build(),
    )
    
    // 业务路由
    r.GET("/api/users", GetUsers)
    r.GET("/api/orders", GetOrders)
    
    r.Run(":8080")
}
```
