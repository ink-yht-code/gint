# 熔断降级

`middlewares/circuitbreaker` 用于在持续失败时打开熔断，防止级联故障。

## 构建器示例

```go
b := circuitbreaker.NewBuilder(circuitbreaker.Config{
	FailureThreshold: 5,
	SuccessThreshold: 3,
	Timeout:          30 * time.Second,
	HalfOpenRequests: 1,
})

r.Use(
	b.WithKeyFunc(func(c *gin.Context) string {
		return c.FullPath()
	}).WithFallback(func(c *gin.Context) {
		c.AbortWithStatusJSON(503, gin.H{
			"code": 503,
			"msg":  "服务暂时不可用",
		})
	}).Build(),
)
```

## 配置

```go
type Config struct {
	FailureThreshold int
	SuccessThreshold int
	Timeout          time.Duration
	HalfOpenRequests int
}
```

## 说明

- 可以通过 `WithKeyFunc` 按路由或依赖分组熔断
- 降级响应应尽量简单稳定
- `HalfOpenRequests` 控制恢复探测阶段允许并发通过的请求数
