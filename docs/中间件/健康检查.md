# 健康检查

`middlewares/health` 提供存活、就绪和聚合健康检查端点。

## 基本使用

```go
health.Health(r,
	health.NewChecker("database", func(ctx context.Context) error {
		return sqlDB.PingContext(ctx)
	}, 3*time.Second),
)
```

## 默认端点

- `/live`
- `/ready`
- `/health`

## 示例响应

```json
{
  "status": "healthy"
}
```

## 建议

- liveness 保持简单
- 外部依赖检查主要放在 readiness 和聚合健康接口里
- 单项检查要设置较短超时，避免探针阻塞
