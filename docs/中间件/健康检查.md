# 健康检查

gint 提供健康检查中间件，支持 Kubernetes liveness 和 readiness 探针。

## 概述

健康检查特性：
- `/health/live` - 存活探针
- `/health/ready` - 就绪探针
- 支持自定义依赖检查
- 支持优雅关闭状态

## 基本使用

### 快速启用

```go
import "github.com/ink-yht-code/gint/middlewares/health"

// 默认配置
health.Health(r)
```

### 自定义配置

```go
health.Health(r, health.Config{
    LivePath:  "/health/live",  // 存活探针路径
    ReadyPath: "/health/ready", // 就绪探针路径
    Checks: []health.Check{
        {Name: "database", Check: checkDatabase},
        {Name: "redis", Check: checkRedis},
    },
})
```

## 探针类型

### 存活探针 (Liveness)

检查服务是否存活，失败则重启容器：

```yaml
# Kubernetes配置
livenessProbe:
  httpGet:
    path: /health/live
    port: 8080
  initialDelaySeconds: 10
  periodSeconds: 10
```

### 就绪探针 (Readiness)

检查服务是否就绪，失败则从负载均衡移除：

```yaml
# Kubernetes配置
readinessProbe:
  httpGet:
    path: /health/ready
    port: 8080
  initialDelaySeconds: 5
  periodSeconds: 5
```

## 自定义检查

```go
func checkDatabase(ctx context.Context) error {
    ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
    defer cancel()
    
    return db.Ping(ctx)
}

func checkRedis(ctx context.Context) error {
    ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
    defer cancel()
    
    return redisClient.Ping(ctx).Err()
}

// 配置健康检查
health.Health(r, health.Config{
    Checks: []health.Check{
        {Name: "database", Check: checkDatabase, Essential: true},
        {Name: "redis", Check: checkRedis, Essential: false},
    },
})
```

## 响应格式

### 成功响应

```json
{
    "status": "ok",
    "checks": {
        "database": "ok",
        "redis": "ok"
    }
}
```

### 失败响应

```json
{
    "status": "error",
    "checks": {
        "database": "ok",
        "redis": "connection refused"
    }
}
```

## 优雅关闭

配合 server 模块实现优雅关闭：

```go
import (
    "github.com/ink-yht-code/gint/server"
    "github.com/ink-yht-code/gint/middlewares/health"
)

func main() {
    r := gin.Default()
    
    // 健康检查
    health.Health(r)
    
    // 业务路由...
    
    // 优雅关闭
    srv := server.New(":8080", r)
    srv.RegisterShutdownHook(func(ctx context.Context) error {
        // 设置服务不健康
        health.SetNotReady()
        return nil
    })
    srv.Run()
}
```

## 完整示例

```go
package main

import (
    "context"
    "time"
    
    "github.com/gin-gonic/gin"
    "github.com/ink-yht-code/gint/middlewares/health"
)

var (
    db    *sql.DB
    redis *redis.Client
)

func main() {
    r := gin.Default()
    
    // 健康检查
    health.Health(r, health.Config{
        LivePath:  "/health/live",
        ReadyPath: "/health/ready",
        Checks: []health.Check{
            {
                Name:       "database",
                Essential:  true,
                Check:      checkDatabase,
            },
            {
                Name:       "redis",
                Essential:  false,
                Check:      checkRedis,
            },
        },
    })
    
    // 业务路由...
    r.GET("/api/data", GetData)
    
    r.Run(":8080")
}

func checkDatabase(ctx context.Context) error {
    ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
    defer cancel()
    return db.PingContext(ctx)
}

func checkRedis(ctx context.Context) error {
    ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
    defer cancel()
    return redis.Ping(ctx).Err()
}
```
